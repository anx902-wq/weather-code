
# 🌱 Hyper Local Agricultural Advisory System

## 📌 About the Project

The **Hyper Local Agricultural Advisory System** is a web-based application designed to help farmers make better farming decisions using location-based weather information and crop guidance.

The project provides current weather details, a 7-day weather forecast, crop information, basic crop suitability guidance, agricultural weather risk alerts, and a farming chatbot.

## 🎯 Objectives

- Provide location-based weather information.
- Display current weather and a 7-day forecast.
- Provide information about different crops and their growing requirements.
- Help users understand basic crop suitability conditions.
- Offer basic weather-related agricultural risk guidance.
- Provide a chatbot to answer common farming questions.

## ✨ Features

### 📍 1. Location Detection
- Detect the user's current location with permission.
- Display latitude and longitude.
- Retrieve the place name when available.

### 🌦️ 2. Weather Forecast
- Display current weather conditions.
- Show temperature, humidity, precipitation, and wind speed.
- Provide a 7-day weather forecast.
- Fetch weather data using the Open-Meteo API.

### 🌾 3. Crop Advisory
- Select from supported crops.
- View crop season, temperature preferences, soil requirements, water needs, and approximate growing duration.
- Review basic crop suitability guidance.

### 🛡️ 4. Agricultural Risk Advisory
- Review temperature conditions.
- Check current precipitation.
- Display basic weather-related farming warnings.

### 🤖 5. AgriGuide Chatbot
- Answer common farming questions.
- Provide basic information about crops, irrigation, fertilizer, weather, and plant diseases.
- Work without an OpenAI API key using predefined responses.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Application logic and interactive features
- **Open-Meteo API** – Weather forecast and weather data
- **Open-Meteo Geocoding API** – Place search and location information
- **Browser Geolocation API** – Current location detection

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the required files are present.
4. Run the website using the VS Code Live Server extension, or another local HTTP server.
5. Open the website in your browser.
6. Allow location permission to use current-location features, or enter a city or village name manually.

## 🔑 API Requirements

The application uses the Open-Meteo public weather and geocoding APIs. An OpenAI API key is not required for the current rule-based chatbot.

An internet connection is required to retrieve weather and geocoding data.

## ⚠️ Limitations

- Crop recommendations are basic guidance and not a guarantee of crop success.
- Crop risk checks use simple rules and are not generated by a trained machine learning model.
- The chatbot uses predefined responses and is not an AI-powered conversational model.
- Accurate farming decisions also depend on soil testing, crop variety, local climate, and expert agricultural advice.
